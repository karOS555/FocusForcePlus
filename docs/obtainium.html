Add FocusForce+ to Obtainium

Obtainium installs FocusForce+ straight from its GitHub releases and keeps it up to date. Play Protect does not block an install that comes this way.

Add to Obtainium

Nothing happened? Then Obtainium is not on this phone yet. Do step 1, come back and tap the button again.

  1. Get Obtainium. Download it from its releases page (the file app-arm64-v8a-release.apk fits almost every phone) or from F-Droid, and install it.
  2. Tap "Add to Obtainium" above, on your phone. Obtainium opens and asks "Import app". Tap Continue.
  3. Install. Tap FocusForce+ in Obtainium's list, then Install. The first time, Android asks whether Obtainium may install apps. Allow it.

The button already switches on "Include prereleases". FocusForce+ is in beta, every version is a prerelease, and without that switch Obtainium finds none.

By hand instead

  1. In Obtainium, tap Add.
  2. Paste https://github.com/karOS555/FocusForcePlus as the app source URL.
  3. Switch on Include prereleases.
  4. Tap Add, then Install.
